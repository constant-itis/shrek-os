# Shrek OS Brand Assets

This directory is the source package for Shrek-owned branding. It is intentionally small: shared color
tokens, helmet marks, terminal assets, wallpaper sources, and consumer-specific staging directories.

## Palette

| Token | Color | Use |
| --- | --- | --- |
| `swamp-ink` | `#12120F` | Primary background, helmet outlines |
| `shrek-green` | `#B1E731` | Primary brand accent |
| `deep-moss` | `#26351D` | Panels, dark secondary surfaces |
| `moss` | `#536B32` | Secondary accents |
| `lichen` | `#91A85A` | Muted highlights |
| `onion-paper` | `#D8D2BF` | Warm light surfaces and text |
| `fog` | `#989A91` | Secondary text |
| `swamp-water` | `#4F9185` | Informational state |
| `torch-amber` | `#D99A38` | Warnings |
| `rust-red` | `#C95143` | Errors and destructive actions |

Chartreuse is an accent, not the whole interface. Default UI is near-black with warm neutral text.
Avoid generic cybersecurity blue/purple gradients. Do not use green alone to mean success; pair state
colors with icons or text.

The detailed helmet is the primary crest. Simplified and monochrome helmets are functional reductions,
not replacements. Supporting graphics should use organic layers, contour lines, roots, and controlled
paths. Do not spread random movie imagery through the OS; the helmet is enough.

Typography direction:

- UI: Inter or Noto Sans
- Terminal/technical: Iosevka or JetBrains Mono
- Wordmark/display: restrained medieval-industrial custom lettering later, not a novelty fantasy font
